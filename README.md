# audioplay
Голосовой помощник на ПК
Для корректной работы данной программы нужны пакеты:
pycaw, SpeechRecognition, keyboard, comtypes.
Команда для установки:
pip install SpeechRecognition keyboard pycaw comtypes
Внешние программы по типу tanks blitz используются мной, вы можете спокойно их удалить если не нужны, также добавлять свое.
Для правильной работы нужен микрофон ну и вывод звука. Интернет для распознавания речи
Python: 3.6+ (рекомендуется 3.8+, протестировано на 3.13).
Если хотите чтобы я что то изменил или добавил, исправил, пишите сделаю.
